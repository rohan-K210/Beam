Test it

  1. Open this page in two to four tabs.
  2. Use the same room name in each tab.
  3. Chat with the room, then pick a peer and send a file.
  4. Stop the Node server: existing chats keep working.

The room limit defaults to 4 and is set by MAX_PEERS_PER_ROOM. Force TURN by adding &relay=1 to the URL.

Privacy

The signaling server only relays SDP and ICE introductions. Chat text and file bytes travel over the mesh's DTLS-encrypted data channels and never reach Node.js.

Join a room

Pick a room name, then open the same link in up to three more browsers or tabs. Everyone in the room gets a direct, encrypted connection to everyone else, and the server steps out of the way.

No accounts. No build step. No server-side chat or file storage.
